# 將Frame.io使用者管理移轉至Admin Console

請連絡您的Frame.io帳戶團隊，將符合資格的V4帳戶轉換為集中式使用者
管理。

>[!NOTE]
>
>Frame.io的網頁和行動應用程式有英文、日文、德文、俄文和英文版本。
>西班牙文、義大利文、法文和巴西葡萄牙文。

在聯絡您的客戶團隊之前，請確認您的組織符合資格要求，並識別需要參與移轉計畫的利害關係人。

- Frame.io V4企業帳戶（在2024年10月或之後建立的帳戶，或已經移轉至V4的帳戶）
- Enterprise和Teams計畫透過Adobe Admin Console和Global Admin Console管理Frame.io。
- 系統管理員存取權以驗證您目前的Frame.io帳戶版本
- 您的Frame.io帳戶團隊的聯絡資訊

## 驗證資格並請求移轉

1. 登入您的Frame.io [enterprise帳戶](https://accounts.frame.io/welcome)，並確認您的帳戶位於V4。
1. 請聯絡您的Frame.io帳戶團隊，要求移轉至Adobe Admin Console使用者管理。
1. 與您的Adobe客戶團隊合作安排移轉時間和推出日期。
1. 向受影響的管理員和使用者傳達任何登入或存取許可權變更。

您的團隊完成移轉後，您就可以在Adobe Admin Console中管理Frame.io使用者並指派角色，而非Frame.io的介面。 現有使用者在轉變期間仍保留其存取權和許可權。

如果您的帳戶不符合資格標準，請聯絡您的Frame.io帳戶團隊，以探索符合Adobe Admin Console使用者管理資格的選項。
