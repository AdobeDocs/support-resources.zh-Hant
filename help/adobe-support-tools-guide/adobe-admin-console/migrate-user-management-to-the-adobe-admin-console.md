# 將使用者管理移轉至Adobe Admin Console

請聯絡您的Adobe客戶團隊，討論如何透過Adobe Admin Console將符合資格的解決方案轉換為集中式使用者管理。

在連絡您的Adobe客戶團隊之前，請確認您的組織符合資格要求，並識別將參與移轉計畫的利害關係人。

移轉資格依解決方案而異。 在開始移轉程式之前，請確定貴組織具備：

- 符合資格的企業解決方案或部署，可支援移轉至Adobe Admin Console型使用者管理。
- 存取適當的Adobe Admin Console 。
- 需要管理存取權才能檢閱您目前的使用者管理設定。
- 您的Adobe客戶團隊或實作代表的聯絡資訊。
- 任何解決方案特定先決條件已完成（如適用）。

## 驗證資格並請求移轉

1. 檢閱您目前的解決方案設定，並確認其支援移轉至Adobe Admin Console型使用者管理。
2. 檢閱任何解決方案特定的資格需求和先決條件。
3. 請連絡您的Adobe客戶團隊，申請移轉至Adobe Admin Console使用者管理。
4. 與您的Adobe客戶團隊合作，檢閱移轉時間、實作需求和組織整備。
5. 向受影響的管理員和使用者傳達任何登入或存取許可權變更。

## 移轉後

移轉一旦完成：

- 使用者管理可透過Adobe Admin Console管理。
- 使用者登入和存取體驗可能會根據組織的身分設定進行更新。
- 除非解決方案另有記錄，否則應透過Adobe Admin Console執行持續的使用者生命週期管理活動。

如果貴組織不符合資格標準，請聯絡您的Adobe客戶團隊，以探索符合Adobe Admin Console使用者管理資格的選項。
