# Experience Cloud 客戶支援指南

無論您是要尋找一對一專家或自助服務的資源，找我們就能得到全世界範圍的協助。

我們致力為您提供領先業界且世界一流的服務和支援，確保您順利邁向成功大道。 我們的宗旨很簡單：我們是客戶的倡導者。 我們的支援團隊由來自各個行業和背景的專業人士組成。 這些專業人士深具技術管理方面的經驗，並對我們廣泛的軟體產品組合有全面的了解。

這份支援指南的製作是為了幫助您熟悉我們的支援產品、計劃、服務和程序，並告訴您如何在世界各地與我們聯絡。
